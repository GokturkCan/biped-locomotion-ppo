# External model access

No robot-description file is distributed or generated by this repository. Authorized users
supply a private JSON `ModelSpec` outside git, containing:

- `model_path`: private MuJoCo model path (relative to that JSON or absolute locally).
- `joint_names`, `actuator_names`: ordered runtime bindings for 12 scalar channels.
- `roles`: semantic left/right hip yaw/roll/pitch, knee extension, ankle pitch/roll roles,
  mapped to those runtime names. The public package contains no source-robot name mapping.
- `contact_geoms`, `contact_bodies`: left/right bindings; `floor_geom`, `root_body`.
- `sensors`: orientation, gravity, global/local velocities, gyro and root-position bindings.
- `reference_qpos`: full runtime reference state, optional `reference_pose_mapping` joint-name overrides, arrays `kp`, `kd`, `effort_limits`, `action_scale`.
- `environment_metadata`: required target/minimum root-height settings and any authorized
  model-specific research overrides. Lists must follow the supplied channel order.

The runtime obtains joint limits from the private model, validates scalar joints/direct unit
transmissions and checks sensor widths. Actuator mapping order must match model actuator
storage order because privileged effort channels follow that order. Roles identify semantics,
not geometry or joint transforms. The source assumes an upright floating base quaternion
in the first seven qpos values and world/body sensor frames compatible with the research code.

`ModelSpec` supplies no geometry, inferred dimensions or fallback model. Missing metadata
fails before reset. External XML includes and meshes remain the authorized user's responsibility.
An arbitrary 12-actuator model is not necessarily compatible with the reported experiment.
Exact compatibility requires private validation of coordinate conventions, contacts, initialization,
settling, reference pose, limits, gains and observations.

Do not commit your ModelSpec, model files, runtime manifests, checkpoints or outputs.
